## Notation Shorthand

- `HH`: hi-hat
- `S`: snare
- `K`: kick
- Count grid: `1 & 2 & 3 & 4 &`

Example:

```text
Count: 1 & 2 & 3 & 4 &
HH:    x x x x x x x x
S:         o       o
K:    o       o
```
